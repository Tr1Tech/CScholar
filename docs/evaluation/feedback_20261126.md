## 3. What the system already does (for the response to the panel)

### The AI

- `backend/app/services/embeddings.py` runs `all-MiniLM-L6-v2`.
- Each study chunk becomes a 384-dimension vector stored in
  `thesis_embeddings.embedding vector(384)`.
- `POST /api/embeddings/search` embeds the query and ranks published studies by
  cosine similarity in pgvector.
- `POST /api/recommendations` ranks against the last viewed/saved study.
- There is no LLM, no generation, and no learned user profile. The honest term
  is **sentence-embedding semantic retrieval**.

### Deletion semantics

| Delete | Actual behavior |
|---|---|
| Program | Blocked while any thesis references it (`ON DELETE RESTRICT`); studies remain. |
| Academic year | Blocked while any thesis references it (`ON DELETE RESTRICT`); studies remain. |
| Category | Removes only `thesis_categories` rows (`ON DELETE CASCADE`); studies remain, tag is lost. |
| Author / Adviser | Removes only the join rows; studies remain, relationship is lost. |
| Thesis | Cascades embeddings, files, reviews, and recommendation logs for that thesis. |
| User | No delete. Deactivate/reactivate only. |

### Security already present

- bcrypt password hashes; generic login errors.
- 24-hour JWT bearer tokens.
- Password-change rotates a fingerprint, revoking older tokens.
- Every protected request re-checks role and `is_active`; deactivation is
  immediate.
- Admin-only routes; CORS allowlist; authenticated PDF delivery.
- `thesis_reviews` keeps every lifecycle decision with reviewer and timestamp.

## 4. Work packages

### WP1 — Trust fixes (P0)

- `backend/app/models.py`: pre-check usage in `delete_program`,
  `delete_academic_year`, `delete_category`; raise a clear error with counts.
- `backend/app/routes/meta.py`: translate the error to `409` with a human

  the server message; offer "View studies" and "Set inactive" where applicable.
- `frontend/.../admin_user_management_screen.dart`: deactivate helper copy.

## 5. Out of scope or needs owner approval

- Persistent login/audit log (requires a new table and endpoints).
- Global site settings (requires a settings table).
- Cascade-deleting studies when a program/year is removed (data loss).
- A generative/chatbot "AI assistant."
- Renaming the approved study title or the "AI Recommendations" label.
